# 本地天气特效备选方案

当前版本不接入天气功能，以保证单文件可直接通过 `file://` 分享和使用。

后续如恢复该能力，建议按以下优先级评估：

1. 浏览器定位授权：用户主动点击后调用 `navigator.geolocation`，以经纬度查询天气；精度较高，但受用户授权和浏览器安全策略影响。
2. IP 地址定位：由服务端或可信第三方将 IP 解析为城市级位置；无需弹窗，但精度较低，并涉及用户网络地址处理。
3. 时区推断：使用浏览器时区推断大致区域；无需权限且可离线，但只能提供粗略的季节或昼夜氛围，不应用于精确天气。
4. 用户手动选择城市：可靠、隐私边界清晰，适合作为前述方案不可用时的兜底。

无论采用哪种方案，都应当：仅在用户主动开启后请求信息；说明会传输的数据与接收方；提供关闭入口；在离线、拒绝权限或查询失败时回退为节气专属动效。
