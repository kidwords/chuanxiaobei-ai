# 中国色浏览器参考配置

本文件记录本地参考项目的色卡展示方式，供当前 384 色浏览器后续校准使用。

## 本地位置

- 参考项目：`D:\git\zhongguo-traditional-colors`
- 页面结构：`explorer.html`
- 色卡与色谱样式：`assets/css/explorer.css`
- 色卡渲染与文字对比度：`assets/js/explorer.js`

## 已采用的展示原则

参考项目在色卡渲染时根据背景色的相对亮度选择文字色：

- 亮度较高：使用深色文字 `#111111`
- 亮度较低：使用浅色文字 `#f7f7f4`
- 色名与 HEX 同时展示，避免只依靠颜色识别
- 选中色卡使用边框强调，不改变原始色值

当前项目已将同样的对比度原则应用到“全部浏览”左侧 384 色列表，并把色名放进色块底部，提高深色和中深色卡片的可读性。
