HELLO — 你好

以理性构建，

我是林墨白，常驻杭州的全栈工程师与数字设计师。过去五年， 我在初创团队、设计工作室与独立开发之间往返，专注于把抽象的 信息结构，转译为清晰、可用、有节奏感的界面。

我的设计哲学脱胎于瑞士国际主义：网格先行，排印为本， 以最少的元素承载最准确的信息。无论是 CRDT 协同文档、 数据可视化，还是三维交互，我都相信秩序本身就是一种美感。
