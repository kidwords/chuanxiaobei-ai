# GLM UI Test · 二十种风格个人网站集

围绕同一虚拟人物「**林墨白 · 全栈工程师 / 数字设计师**」，用 **20 套完全独立的设计系统** 呈现同一份个人主页内容。每个站点拥有自己的色彩体系、字体方案、布局结构与交互逻辑——**绝非简单换皮**。

## 快速开始

直接用浏览器打开根目录的 `index.html` 即可进入总览首页，从首页可点击进入任意一个风格站点。

> 也可用本地服务器（推荐，避免个别浏览器对 `file://` 的限制）：
>
> ```bash
> cd glm_ui_test
> python -m http.server 8765
> # 然后访问 http://localhost:8765/
> ```

## 技术特性

- **零依赖**：纯原生 HTML / CSS / JavaScript，无需构建，无前端框架。
- **单文件**：每个站点一个 `index.html`，CSS 与 JS 全部内联。
- **简体中文**：全部页面 `lang="zh-CN"`，内容完整汉化。
- **响应式**：适配 375px / 768px / 1024px / 1440px 等主流断点。
- **可访问性**：
  - 语义化 HTML 结构（`header` / `nav` / `main` / `section` / `footer`）
  - 图标按钮带 `aria-label`，图片带 `alt`
  - 可见焦点环（`:focus-visible`）
  - 键盘可达，移动端菜单支持 Escape 关闭
- **动效克制**：
  - 全部尊重 `prefers-reduced-motion`，关闭动画时降级为静态展示
  - 交互过渡控制在 150–300ms
- **图标规范**：功能图标统一使用内联 SVG（Heroicons 风格），不使用 emoji 充当功能图标。

## 设计依据

本项目的视觉规范参考了 `ui-ux-pro-max` 设计智能库，包括：

- 新拟态：圆角 12–16px，双向柔和阴影，单色粉彩
- 毛玻璃：`backdrop-filter: blur(15px)`，半透明 15–30% + 1px 浅色描边
- 交付前检查清单：对比度 ≥ 4.5:1、可点击元素 `cursor: pointer`、悬停反馈平滑等

## 浏览说明

总览首页支持按风格分类筛选（柔和质感 / 强烈视觉 / 现代主义 / 实验交互），每张卡片带有该风格的纯 CSS 缩略预览、配色板与简介。每个子站点右上角或导航栏都有「← 返回总览」链接可回到首页。
