Nº 01No. One

关于 — a few words about the maker

作者侧记

林墨白，1996 年生于浙江。白天写代码，夜里读旧书。常于西湖边的小馆临窗而坐，为一行 CSS 排版苦恼至深夜。

  • 古典文学
座右铭

"Simplicity is the ultimate sophistication."

五年来，林墨白始终在一处微妙的地带工作——左手指尖敲打着冰冷的逻辑，右眼却盯着屏幕上每一处像素的呼吸。他相信，工程师与设计师从来不是两种职业，而是同一种专注的两个侧面：一种对秩序的痴迷，与一种对美的克制。

他的作品少而慢。一个按钮的圆角可以争论三天，一处字距的调整值得为一个项目重启七次。在他看来，所谓"用户友好"并不来自堆砌功能，而是来自一次次删减——删到只剩骨架，再轻轻覆上一层皮肤，让它能呼吸。

"设计的尽头是克制，工程的尽头是优雅。" — 林墨白 · 设计手记

他习惯用笔记本来记录灵感，纸页泛黄，钢笔字迹潦草。每一行代码上线前，他都会问自己三个问题：它是否诚实？它是否温柔？它是否经得起五年后的回望？若三者皆"是"，方才放手。

如今他定居杭州，在一家产品型公司担任全栈工程师与设计负责人。工作之外，他热衷于修复旧字体、研究活版印刷、并为开源社区贡献微小的工具。这些看似无用之事，恰恰是他灵感最深的泉眼。
